# User Manual — Bank Reports RAG System

## 1. Prerequisites

- Python 3.10+ (tested on 3.14)
- An OpenAI API key with access to `text-embedding-3-large`, `gpt-4o-mini`
- PDFs placed in `data_pdf_files/`

## 2. Setup

```powershell
# from the RAG/ directory
python -m venv .venv
.venv\Scripts\Activate.ps1          # PowerShell
# or: .venv\Scripts\activate.bat    # cmd.exe

pip install -r requirements.txt
```

Create/confirm a `.env` file in `RAG/` with at least:

```
OPENAI_API_KEY=sk-...
```

(LangSmith tracing, Tavily, email/Pushover keys are optional and only used if
you wire in those integrations yourself — they are not required to run this
system.)

> **Never commit `.env`.** It already contains live API keys — `.gitignore`
> excludes it, but double-check before pushing this folder anywhere.

## 3. Ingest your PDFs

Ingestion parses every PDF in `data_pdf_files/`, cleans it, chunks it,
enriches metadata, embeds it, and stores it in the local Chroma vector store
(`chroma_db/`, created automatically).

```powershell
# ingest everything
python -m src.ingest

# ingest specific files only
python -m src.ingest --files "Boardresults30062026_BOI.pdf" "q1fy27-earnings-presentation.pdf"

# quick smoke test: only the first 2 discovered PDFs
python -m src.ingest --limit 2
```

Notes:
- Re-running ingestion on the same file is **safe and idempotent** — chunk
  IDs are deterministic hashes of (file, page, content type, text), so
  re-ingesting overwrites the same chunks instead of duplicating them.
- Image captioning calls the OpenAI vision model once per extracted
  image/chart on first ingestion; captions are cached in
  `.image_cache/captions.json` by image hash, so re-ingestion is much cheaper
  after the first run.
- Expect a large investor-presentation PDF (many pages/charts) to take
  several minutes on first ingestion because of the vision-captioning calls.
- Set `CAPTION_IMAGES = False` in `src/config.py` to skip image captioning
  entirely (faster, no chart/image content indexed).

## 4. Ask questions (Gradio UI)

```powershell
python app.py
```

This opens a local Gradio app (URL printed in the terminal, typically
`http://127.0.0.1:7860`) with three tabs:

- **Chat** — ask questions in natural language; answers cite `(Source: file, p.N)`
  for every claim and list the retrieved source chunks below the answer.
- **Ingest** — trigger ingestion from the browser and watch the log; useful
  after dropping new PDFs into `data_pdf_files/`.
- **Evaluation** — run the retrieval/embedding evaluation and view Hit Rate,
  Precision/Recall@k, MRR, NDCG, and mean similarity, plus a per-question
  breakdown table.

### Command-line alternative

```powershell
python -c "from src.rag_chain import get_rag_chain; print(get_rag_chain().answer('What was net profit for Q1 FY27?').answer)"
```

## 5. Run evaluation from the CLI

```powershell
python -m src.evaluation
```

- If `eval/eval_dataset.json` does not exist, a 15-question **synthetic**
  eval set is auto-generated by sampling indexed chunks and asking the LLM
  what question each one answers, then saved to that file.
- Results are saved to `eval/results/<timestamp>.json` / `.csv` and mirrored
  to `eval/results/latest.json` / `.csv`.
- To evaluate with a different top-k: edit the `k` argument in
  `evaluate_retrieval(k=5)` (or use the Evaluation tab's slider in the UI).

### Writing your own eval questions

Replace `eval/eval_dataset.json` with real analyst questions once available,
in this format:

```json
[
  {"question": "What was Union Bank's net profit in Q1 FY27?", "source": "financial-results-june-30-2026_union bank.pdf", "page": 4}
]
```

`source` must exactly match the PDF filename in `data_pdf_files/`; `page` is
the 1-indexed page where the answer lives. Real labels are far more trustworthy
than the synthetic bootstrap set — swap them in as soon as you have them.

## 6. Re-indexing after changing the embedding model

If you change `EMBEDDING_MODEL` or `EMBEDDING_DIMENSIONS` in `src/config.py`,
you **must** wipe and rebuild the vector store — old and new vectors are not
comparable:

```powershell
# stop any running app.py first, then:
Remove-Item -Recurse -Force chroma_db
python -m src.ingest
```

## 7. Troubleshooting

| Symptom | Likely cause / fix |
|---|---|
| `OPENAI_API_KEY` errors | Confirm `.env` is in `RAG/` (not a subfolder) and has no quotes/spaces around the key. |
| Ingestion very slow on first run | Vision captioning of every chart; set `CAPTION_IMAGES = False` in `src/config.py` for a text/table-only faster pass. |
| Retrieval returns nothing | Vector store is empty — run `python -m src.ingest` first. |
| Chat answers say "not in context" for something you know is in a PDF | Re-check the PDF was ingested (`python -m src.ingest --files <file>`), or the section is a chart-only page and `CAPTION_IMAGES` was off during ingestion. |
| `sentence-transformers`/reranker download is slow the first time | The cross-encoder model (`ms-marco-MiniLM-L-6-v2`) downloads from Hugging Face on first use and is cached under `~/.cache/huggingface` afterward. |
